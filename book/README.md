# Meaning by Design: A Hands-On Guide to Persuasion, Identity, and Visual Language

This mini textbook explores how ordinary products and ideas become meaningful through communication. It moves from persuasion and decision-making to brand archetypes and design history, then applies all three lenses to different presentations of the same plain white T-shirt. The final chapter connects the framework to bounded AI-assisted work, deterministic checks, human review, and Git.

## How to Use This Guide

Read the chapters in order if you are new to the ideas. Each chapter adds a lens that becomes more useful in the next one. While reading, keep the plain white T-shirt in mind and ask how its meaning changes when the audience, story, persuasive goal, or visual language changes.

You can also use the guide as a working checklist:

- Start with Chapter 1 when you need to clarify the response a message should enable.
- Use Chapter 2 when you need to describe the identity or meaning a brand is expressing.
- Use Chapter 3 when you need to analyze or choose a visual language.
- Use Chapter 4 when you want to compare several presentations of one unchanged product.
- Return to Chapter 5 when directing AI, writing a specification, planning checks, or reviewing a generated result.
